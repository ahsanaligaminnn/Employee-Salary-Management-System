# Employee Salary Management System

A Python-based console application that manages employee information, analyzes monthly sales, and calculates performance-based salary bonuses.

## Features
- Employee information management
- Input validation for age, salary, and sales
- Total, average, highest, and lowest sales calculations
- Performance-based bonus calculation
- Final salary calculation
- Organized employee report

## Technologies Used
- Python 3
- Variables and data types
- While loops and for loops
- If-elif-else conditions
- Functions
- Lists and dictionaries
- Input validation

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python employee_salary.py
```

## Purpose
This project was built to practice Python fundamentals through a practical employee salary and sales management scenario.
